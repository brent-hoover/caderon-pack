name: markdown-review
description: Serve agent-authored markdown docs to the browser for reading and feedback
argument-hint: Optional absolute path to a markdown doc to add to the review session
---

Invoke the `markdown-review` skill.

If a markdown file path is passed as an argument, add it to the current review session (starting a new session if needed). If no argument is provided, follow the skill's instructions for managing an existing session.
