---
name: obs-daily-note
description: Append content to today's Obsidian daily note (Journal/YYYY-MM-DD.md). Creates it if it doesn't exist.
---

The user wants to add something to their Obsidian daily note.

If they passed text as the argument, use that as the content directly.
If no argument was given, ask them what they want to add.

Call the `daily_note` MCP tool with the content.
Confirm what was added and to which file.
