# excalidraw-diagrams

Generate and edit Excalidraw (`.excalidraw`) diagram files for architecture, network topology, and Kubernetes infrastructure diagrams.

## Skills

### excalidraw

Generate `.excalidraw` files from text descriptions. Supports:

- Kubernetes architecture diagrams (pods, services, deployments, namespaces, etc.)
- Network topology diagrams
- General architecture diagrams
- Iterative editing (move, recolor, align, add/remove elements)
- Company style guide with consistent colors and conventions
- Templates for common diagram types

## Usage

Open the generated `.excalidraw` files in the Excalidraw desktop app or at excalidraw.com.

## Installation

```bash
claude plugin install excalidraw-diagrams@timonier-ai-tools
```
